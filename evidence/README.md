# Evidence Archives

`archives/version1_evidence.zip` is the compact runtime evidence bundle used by the Version 2 notebook. It contains the frozen Step 3B screening output, Version 1 seed manifest, Step 8 frozen cases, and the frozen 150-case development regression package.

The raw Kaggle CSV, mapping table, processed retrieval corpus, evaluation cases, predictions, metrics, and failure analysis are also provided separately in this repository. Earlier intermediate archives that duplicate these materials are retained in the final course submission package rather than repeated here.

`archives/version2_regression_evidence.zip` is the frozen Version 2 evidence export. `supplementary_not_reported/` contains the separately labelled 24-case functional run that is not used as the primary reported result.
